# Контрольные вопросы к ЛР №6

1. **Задача Коши для ДУ 1 порядка.** Найти функцию `y = y(x)`, удовлетворяющую уравнению `y′ = f(x, y)` на отрезке `[x₀, xₙ]` и начальному условию `y(x₀) = y₀`. Дополнительное условие задано в одной точке — поэтому задача Коши, а не краевая.
2. **Что является решением.** Всякая дифференцируемая функция `y = φ(x)`, обращающая уравнение в тождество: `φ′(x) = f(x, φ(x))`. Общее решение содержит одну произвольную постоянную `y = φ(x, C)`; частное получается при `C = C₀` из начального условия.
3. **Суть метода конечных разностей.** Отрезок непрерывного изменения аргумента заменяется дискретным множеством узлов (разностной сеткой), искомая функция — сеточной функцией `yᵢ`, а дифференциальное уравнение — разностным уравнением относительно `yᵢ`. Производные заменяются конечно-разностными отношениями.
4. **Разностная аппроксимация.** Замена производной конечной разностью, например `y′(xᵢ) ≈ (yᵢ₊₁ − yᵢ)/h`; в результате дифференциальное уравнение переходит в разностное, определённое на сетке.
5. **Геометрический смысл задачи Коши.** Найти ту интегральную кривую семейства `y = φ(x, C)`, которая проходит через заданную начальную точку `M₀(x₀, y₀)`.
6. **Интегральная кривая.** График частного решения дифференциального уравнения. В каждой её точке наклон касательной равен `f(x, y)`. Линия постоянного наклона `f(x, y) = k` называется изоклиной.
7. **Условия существования и единственности.** Непрерывность `f(x, y)` в замкнутой области `D̄` — условие **существования**. Условие Липшица по `y`: `|f(x, y₁) − f(x, y₂)| ≤ k|y₁ − y₂|` (или непрерывность `f′_y`) — условие **единственности**.
8. **Что должно быть задано.** Правая часть `f(x, y)`, начальные условия `x₀` и `y₀ = y(x₀)`, интервал интегрирования `[x₀, xₙ]`, шаг `h` и требуемая точность `ε`. Для многошаговых методов дополнительно нужны разгонные значения `y₁, y₂, y₃`.
9. **Порядок точности.** Метод Эйлера — первый, `δₙ = O(h)`. Метод Эйлера с пересчётом — второй, `O(h²)`. Метод Рунге-Кутта 4-го порядка — четвёртый, `O(h⁴)`. В программе это подтверждено экспериментально: при делении шага пополам погрешность Эйлера падает примерно в 2 раза, Рунге-Кутта — примерно в 16.
10. **Основные одношаговые методы.** Метод Эйлера, усовершенствованный метод Эйлера (с пересчётом), методы Рунге-Кутта II и IV порядков. Одношаговый — значит `yᵢ₊₁` вычисляется только по `yᵢ`, поэтому шаг можно менять в любой момент и метод самостартующий.
11. **Основные многошаговые методы.** Методы Адамса (Адамса-Башфорта — явный, Адамса-Моултона — неявный), методы прогноза и коррекции на их основе, метод Милна. Значение `yᵢ₊₁` считается по k предыдущим значениям `yᵢ₋ₖ₊₁, …, yᵢ`.
12. **Суть методов прогноза и коррекции.** На каждом шаге два этапа. Предиктор — явная формула, даёт грубое приближение `y⁽⁰⁾ᵢ₊₁`. Корректор — неявная формула, в правую часть которой входит `f(xᵢ₊₁, yᵢ₊₁)`; она итерируется, уточняя значение. У Адамса это `h/24·(55fᵢ − 59fᵢ₋₁ + 37fᵢ₋₂ − 9fᵢ₋₃)` и `h/24·(9fᵢ₊₁ + 19fᵢ − 5fᵢ₋₁ + fᵢ₋₂)`.
13. **Когда переходить к следующему узлу.** Когда очередная коррекция перестаёт менять результат: `|y⁽ᵏ⁺¹⁾ᵢ₊₁ − y⁽ᵏ⁾ᵢ₊₁| ≤ ε`. Если сходимости нет за разумное число итераций, шаг h надо уменьшить — в программе это отдельная диагностика.
14. **Правило Рунге.** `R = (y_h − y_{h/2})/(2ᵖ − 1)`, где `y_h` и `y_{h/2}` — решения в одном узле при шагах h и h/2, p — порядок метода. Позволяет оценить погрешность без знания точного решения. Контроль ведут либо на каждом шаге, либо на конце интервала; если `R > ε`, шаг делят пополам и пересчитывают. В работе правило Рунге применяется к методам Эйлера и Рунге-Кутта.
15. **Чтобы «запустить» метод Адамса.** Нужны значения в четырёх последовательных узлах: `y₀` задано начальным условием, а `y₁, y₂, y₃` вычисляются одношаговым методом — в программе методом Рунге-Кутта 4-го порядка того же порядка точности. Тогда доступны `f₀…f₃`, и расчёт можно начинать с `y₄`.

## Что объяснить на своём варианте

- Вариант 19 → строка таблицы 1: методы **1, 3, 4** — Эйлер, Рунге-Кутта 4-го порядка, Адамс (предиктор-корректор). Милн (метод 5) в вариант не входит.
- Оценка точности разная по заданию: правило Рунге для методов 1 и 3, точное решение `ε = max|yᵢточн − yᵢ|` для метода 4.
- Основной набор — пример 1 из лекции: `y′ = y + (1+x)y²`, `y(1) = −1`, `[1; 1.5]`, `h = 0.1`. Уравнение Бернулли; подстановка `v = 1/y` даёт `v′ + v = −(1+x)`, откуда `y = 1/(C·e^(−x) − x)`, а при `y(1) = −1` постоянная `C = 0` и `y = −1/x`.
- Значения совпали с таблицами лекции: Эйлер `−0.9, −0.8199, −0.753998, −0.698640, −0.651361`; Рунге-Кутта `−0.909093, −0.833337, −0.769234, −0.714289, −0.666670`.
- Погрешности прямого расчёта при `h = 0.1`: Эйлер `1.56·10⁻²`, Рунге-Кутта `3.72·10⁻⁶`, Адамс `7.45·10⁻⁶`.
- При `ε = 10⁻⁶` правило Рунге принимает решение Рунге-Кутта на `h = 0.05` (11 узлов), а Эйлера — на `h ≈ 6.10·10⁻⁶` (81921 узел). Адамс по точному решению принимается на `h = 0.05`. Это цена первого порядка точности Эйлера.
- Почему Адамс чуть хуже Рунге-Кутта на этом наборе: первые узлы он наследует от разгона, дальше добавляется собственная погрешность предиктора и корректора. Экономия — одно-два вычисления `f(x, y)` на шаг против четырёх.
- В лекции формула (17) записана с множителями `h²/2`, `5h³/12`, `3h⁴/8` при разностях. Конечные разности `∆ᵏfᵢ` уже безразмерны относительно h, поэтому общим множителем должно быть `h`: `y_{i+1} = y_i + h(f_i + ½∆f_i + 5/12∆²f_i + 3/8∆³f_i)`. Именно эта запись раскрывается ровно в предиктор (18) — в проекте есть тест, который это проверяет.
- Оценка по точному решению возможна только потому, что все пять предлагаемых уравнений решаются в квадратурах. Для произвольного `f(x, y)` доступно лишь правило Рунге.
