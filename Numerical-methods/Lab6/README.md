## Вариант и методы

По таблице 1 задания варианту 19 соответствуют методы **1, 3, 4**:

| № | Метод | Тип | Порядок p | Оценка точности |
|---|---|---|---|---|
| 1 | Эйлера | одношаговый | 1 | правило Рунге |
| 3 | Рунге-Кутта 4-го порядка | одношаговый | 4 | правило Рунге |
| 4 | Адамса (предиктор-корректор) | многошаговый | 4 | точное решение: ε = max\|y точн − y_i\| |

Правило Рунге: `R = (y_h − y_h/2)/(2^p − 1)`. Программа считает R во всех общих узлах
двух сеток и делит шаг пополам, пока `R > ε`.

Метод Адамса: предиктор `y_{i+1} = y_i + h/24·(55f_i − 59f_{i−1} + 37f_{i−2} − 9f_{i−3})`,
корректор `y_{i+1} = y_i + h/24·(9f_{i+1} + 19f_i − 5f_{i−1} + f_{i−2})` — итерируется
до `|y^(k+1) − y^(k)| ≤ ε`. Значения `y1, y2, y3` получены методом Рунге-Кутта.

## Уравнения

| id | y′ = f(x, y) | Точное решение |
|---|---|---|
| `linear` | y | y = y₀·e^(x−x₀) |
| `sum` | x + y | y = (y₀+x₀+1)·e^(x−x₀) − x − 1 |
| `square` | y − x² + 1 | y = (x+1)² + C·e^x |
| `bernoulli` | y + (1+x)·y² | y = 1/(C·e^(−x) − x) |
| `gauss` | −2·x·y | y = y₀·e^(x₀²−x²) |
| `stiff` | −5y + 5x² + 2x | y = x² + C·e^(−5x) |

Основной набор — пример 1 из лекции: `y′ = y + (1+x)y²`, `y(1) = −1`, `[1; 1.5]`, `h = 0.1`.
При этих данных точное решение равно `y = −1/x`, а значения методов Эйлера и Рунге-Кутта
совпадают с таблицами примеров 1 и 3 лекции. Это закреплено автоматическими тестами.

## Форматы данных

JSON:

```json
{
  "equation": "bernoulli",
  "x0": 1,
  "y0": -1,
  "xn": 1.5,
  "h": 0.1,
  "epsilon": 1e-6
}
```

Текст — по строке на поле, разделитель `=` или `:`:

```text
# комментарий
equation = square
x0 = 0
y0 = 0,5
xn = 2
h = 0,2
epsilon = 1e-6
```

Запятая служит десятичным знаком. Поле `epsilon` необязательно, по умолчанию `1e-6`.
Лишние поля в JSON (например `comment`) игнорируются, в текстовом формате — отклоняются.

## Особенности

- Проверяются `xn > x0`, `h > 0`, `h ≤ xn − x0`, `0 < ε < 1` и предел в 200 000 узлов.
- Метод Адамса требует не менее четырёх шагов. При более крупном h он объявляется
  неприменимым, а одношаговые методы продолжают работать.
- Если итерации корректора не сходятся за 20 шагов, метод Адамса сообщает об этом
  и предлагает уменьшить h, вместо того чтобы выдавать заведомо неверные числа.
- Расходящееся решение (переполнение) диагностируется с указанием узла, а не превращается в `NaN`.
- Число итераций корректора выводится: 3–4 на задаче варианта, 7–10 при h = 0.25,
  расходимость на жёсткой задаче при h = 0.5.
- Явные методы условно устойчивы. На наборе `stiff-euler-diverges` шаг h = 0.5 нарушает
  условие h < 2/5, и метод Эйлера даёт нарастающие осцилляции — это ожидаемое поведение,
  показанное намеренно.
- Погрешность по точному решению доступна только потому, что все предлагаемые уравнения
  решаются в квадратурах. В общем случае остаётся правило Рунге.
- График в браузере: масштабирование кнопками/колесом, перетаскивание, сброс, экспорт SVG.
- Отдельный график погрешности в логарифмическом масштабе показывает её накопление вдоль интервала.
