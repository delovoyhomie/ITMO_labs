# Numerical Methods Lab 3 — Численное интегрирование (вариант 19)

Приближённое вычисление определённого интеграла различными квадратурными методами
с автоматическим выбором числа разбиений по правилу Рунге, а также исследование
сходимости несобственных интегралов 2 рода.

Интеграл вычислительной части: `∫ от 2 до 4 (x³ − 3x² + 6x − 19) dx = 2`.

## Запуск веб-интерфейса

```bash
npm run gui
```

После запуска открыть `http://127.0.0.1:4174`.
Интерфейс использует React через ESM CDN `esm.sh`, поэтому при первом открытии нужен доступ в интернет.

## Консольное приложение

```bash
npm start
```

Ввод данных с клавиатуры: тип интеграла (определённый / несобственный), функция, метод,
пределы, точность ε. Можно также загрузить параметры из JSON-файла:

```bash
npm run demo:proper
npm run demo:improper
```

## Отчёт

```bash
npm run report
```

Создаёт `variant19-report.md` с вычислительной частью варианта 19.
Полный отчёт в LaTeX — `lab3-variant19-report.tex` (компилируется в `lab3-variant19-report.pdf`).

## Реализованные методы

- Прямоугольники: левые, правые, средние.
- Трапеции.
- Симпсон (парабол).
- Ньютона — Котеса (для вычислительной части отчёта, n = 6).
- Правило Рунге для оценки погрешности и автоматического выбора n (начальное n = 4).

## Структура

- `src/function-evaluator.js` — класс вычисления значений функции.
- `src/data/functions.js` — набор функций (5 определённых, 3 несобственных) и список методов.
- `src/methods/integration.js` — квадратурные формулы.
- `src/methods/improper.js` — исследование несобственных интегралов 2 рода.
- `src/runge.js` — адаптивное интегрирование по правилу Рунге.
- `src/solver.js` — общая логика для веб-интерфейса и CLI.
- `src/plotting-core.js` — построение SVG-графика с заливкой площади интеграла.
- `web/` — веб-интерфейс (index.html, styles.css, app.js).
