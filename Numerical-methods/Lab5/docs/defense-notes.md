# Контрольные вопросы к ЛР №5

1. **Когда нужна интерполяция?** Когда функция известна в отдельных узлах, а требуется её значение между ними. Например, для экспериментальной таблицы или восстановления промежуточных значений.
2. **Отличие от аппроксимации.** Интерполянт проходит через все выбранные узлы. Аппроксимация подбирает общую зависимость по критерию близости и может не проходить через них.
3. **Сущность задачи.** Построить функцию P такую, что P(xᵢ)=yᵢ, и вычислить P(x*) при заданном x*.
4. **Интерполяция и экстраполяция.** Первая вычисляет значения внутри диапазона узлов, вторая — вне него. При экстраполяции ошибка может быстро расти.
5. **Линейная интерполяция.** По двум узлам: P₁(x)=y₀+(y₁−y₀)(x−x₀)/(x₁−x₀).
6. **Квадратичная интерполяция.** По трём узлам строится полином степени не выше двух, например P₂(x)=Σᵢ yᵢ∏ⱼ≠ᵢ(x−xⱼ)/(xᵢ−xⱼ), i,j=0,1,2.
7. **Лагранж.** Для каждого узла строится базис ℓᵢ, равный 1 в своём узле и 0 во всех остальных; P=Σyᵢℓᵢ.
8. **Разделённые разности.** Нулевой порядок f[xᵢ]=yᵢ; первый f[xᵢ,xᵢ₊₁]=(yᵢ₊₁−yᵢ)/(xᵢ₊₁−xᵢ).
9. **Ньютон.** К полиному последовательно добавляются слагаемые с произведениями (x−xⱼ); коэффициенты равны разделённым разностям. Новый узел позволяет добавить новое слагаемое, сохранив старые.
10. **Графическая интерпретация.** Кривая проходит через заданные точки; искомое значение — ордината этой кривой при x*.
11. **Конечные и разделённые разности.** Разделённые применяются для любых различных узлов. Интерполяционные формулы с конечными разностями требуют одинакового шага h.
12. **Ньютон вперёд/назад.** Вперёд удобно около левого конца, t=(x−x₀)/h; назад — около правого, t=(x−xₙ)/h. Полные формы математически эквивалентны.
13. **Гаусс вперёд/назад.** Около центрального узла a: I обычно при x>a, II при x<a. Направления отличаются порядком подключения соседних узлов и выбором диагонали разностей.
14. **Стирлинг.** Симметричная нечётная таблица, x близок к центральному узлу; рекомендуется |t|≤0.25. Это среднее двух формул Гаусса.
15. **Бессель.** Чётная таблица, x близок к середине центральной пары; рекомендуется 0.25≤t≤0.75, где t отсчитывается от левого узла этой пары.
16. **Глобальная/локальная интерполяция.** Глобальная использует один полином для всех узлов. Локальная строит отдельные зависимости на частях интервала или использует ближайшие узлы.
17. **Кубические сплайны.** На каждом промежутке задаётся кубический полином. В узлах соседние полиномы согласуются по значению, первой и второй производным; для единственности добавляют граничные условия, например нулевую вторую производную на концах.
