# Numerical Methods Lab 5

Лабораторная работа №5 «Интерполяция функции», вариант 19.
Оформление отчёта и веб-интерфейса основано на [ЛР №4](https://github.com/delovoyhomie/ITMO_labs/tree/main/Numerical-methods/Lab4).
Титульный лист сохранён: Якименко Владислав Игоревич, Р3213; Малышева Татьяна Алексеевна.

## Запуск

Нужен Node.js 20 или новее. Сторонних npm-зависимостей нет.
Откройте терминал в папке `Lab5`.

```bash
npm start
npm run gui
```

`npm start` открывает консольное меню: клавиатура, файл, функция или таблица варианта.
Веб-интерфейс: [http://127.0.0.1:4175](http://127.0.0.1:4175).
Для остановки сервера нажмите Ctrl+C. Другой порт можно задать переменной `PORT`.

```bash
npm run demo:file
npm run demo:function
npm test
npm run report
```

`npm run report` пересчитывает Markdown, TXT и SVG. Готовый академический отчёт находится в
`ВЫЧМАТ ЛР5 Р3213 Якименко.pdf`, редактируемый исходник — `lab5-variant19-report.tex`.
Для повторной сборки PDF нужен Tectonic или TeX Live. Шрифты Computer Modern Unicode
включены в `docs/fonts` вместе с лицензией OFL, чтобы сборка Tectonic/XeLaTeX
сохраняла оформление независимо от установленных в системе шрифтов:

```bash
tectonic lab5-variant19-report.tex
# Альтернатива: выполнить pdflatex дважды для оглавления.
pdflatex -interaction=nonstopmode lab5-variant19-report.tex
pdflatex -interaction=nonstopmode lab5-variant19-report.tex
```

PDF использует сохранённые изображения из `docs`. После изменения интерфейса или графиков
их PNG-снимки следует обновить перед повторной сборкой отчёта.

## Вариант и результат

Таблица 1.4 задания:

| x | 1.05 | 1.15 | 1.25 | 1.35 | 1.45 | 1.55 | 1.65 |
|---|---|---|---|---|---|---|---|
| y | 0.1213 | 1.1316 | 2.1459 | 3.1565 | 4.1571 | 5.1819 | 6.1969 |

- X₁ = 1.573: вторая формула Ньютона, t = −0.77; **5.421616273004**.
- X₂ = 1.375: первая формула Гаусса, центр 1.35, t = 0.25; **3.406628713989**.
- Лагранж подтверждает оба результата.

Методы программы по варианту: 1, 2, 3 — Лагранж, обе формулы Ньютона с разделёнными
разностями, обе формулы Ньютона с конечными разностями. Дополнительно реализованы
Гаусс I/II, Стирлинг и Бессель.

## Командная строка

```bash
node src/index.js --variant19
node src/index.js --input examples/variant19.json --x 1.375
node src/index.js --input examples/decimal-comma.txt --x 0.25
node src/index.js --function sin --a 0 --b 3.141592653589793 --count 7 --x 0.7

```

Если аргументы не заданы в параметре `--x` или файле, программа запросит x с клавиатуры.
При двух аргументах текстовый вывод содержит оба расчёта, а `--graph` сохраняет график первого.

## Форматы данных

JSON:

```json
{
  "points": [[0, 1], [1, 2], [2, 5]],
  "targets": [0.5, 1.5]
}
```

Также принимаются `points: [{"x": 0, "y": 1}, ...]`, массив пар без объекта-обёртки
или объект с массивами `x` и `y` одинаковой длины. `targets` необязателен;
для одной точки можно задать `target`.

Текст — пробел или точка с запятой между координатами:

```text
x;y
0,0;1,0
0,5;1,25
1,0;2,0
```

Заголовок `x y`/`x;y`, пустые строки и строки с `#` допустимы. Запятая служит
десятичным знаком, поэтому разделитель координат «запятая» не используется.
JSON сохраняет стандартный синтаксис чисел с точкой; числа с запятой можно передать строками.
Необязательная метка `functionId` (`sin`, `exp`, `cubic`) проверяется на соответствие
табличным значениям; у произвольной таблицы её следует убрать.

## Особенности

- Узлы сортируются. Совпадающие и машинно неразличимые x отклоняются.
- От 2 до 50 точек; верхний предел выбран для интерактивной программы.
- На неравномерной сетке применимы Лагранж и обе формулы разделённых разностей.
- Центральные схемы используют весь набор. Гаусс/Стирлинг требуют нечётного числа
  равноотстоящих узлов, Бессель — чётного. Это ограничение реализованных полных схем.
  Узлы автоматически не отбрасываются. Для Бесселя подготовлен отдельный чётный набор.
- Направление Ньютона выбирается относительно середины интервала. Для Гаусса
  выбирают I справа от центра, II слева; в программе можно сравнить оба результата.
- Стирлинг рекомендуется при |t| ≤ 0.25, Бессель — при 0.25 ≤ t ≤ 0.75.
  Вне рекомендуемой зоны полный полином вычисляется, но округления могут сильнее влиять на результат.
- Экстраполяция разрешена с предупреждением. При числе узлов больше 15 выводится
  предупреждение о возможных осцилляциях и накоплении ошибок.
- На одинаковых узлах все полные формы задают один полином. Малое расхождение методов
  не равно малой ошибке относительно неизвестной исходной функции.
- Для известных функций программа выводит f(x) и абсолютную ошибку. Для таблицы без
  аналитической функции исходные значения соединяются ломаной, а интерполяционный
  полином выводится отдельной линией.
- График в браузере: масштабирование кнопками/колесом, перетаскивание, сброс, экспорт SVG.
