# Лабораторная работа №1

## База знаний Prolog и онтология в Protégé

**Модуль:** Базы знаний и онтологии

**Тематика базы знаний:** профили видеоигр

## Цель работы

Создать базу знаний на языке Prolog, описать игровые объекты, их свойства и
отношения, а затем выполнить запросы разной сложности с использованием фактов,
переменных, правил и логических операторов.

## Состав работы

- `games.pl` — база знаний с комментариями;
- `run_examples.pl` — сценарий, автоматически выполняющий примеры запросов;
- `queries.md` — запросы для ручного запуска и ожидаемые результаты;
- `part_2_ontology/games_ontology.owl` — основная OWL-онтология в RDF/XML;
- `part_2_ontology/games_ontology.ttl` — читаемая версия в Turtle;
- `part_2_ontology/dl_queries.txt` — запросы для проверки reasoner-ом;
- `part_2_ontology/README.md` — описание перевода Prolog в OWL и инструкция.

База содержит:

- 51 факт с одним аргументом;
- 15 фактов с двумя аргументами;
- 7 правил;
- правила и запросы с логическими операторами И (`,`), ИЛИ (`;`) и НЕ (`\+`).

## Запуск

Для выполнения требуется [SWI-Prolog](https://www.swi-prolog.org/).

### Автоматическая демонстрация

Из каталога лабораторной работы выполните:

```bash
swipl -q -s run_examples.pl
```

### Интерактивный режим

```bash
swipl
```

Загрузите базу знаний:

```prolog
?- [games].
```

После этого можно вводить запросы из файла `queries.md`. Чтобы получить
следующее решение запроса, нажмите `;`, для завершения поиска — Enter.

## Использованные обозначения

- Переменные начинаются с заглавной буквы: `Game`, `Studio`.
- Атомы начинаются со строчной буквы: `minecraft`, `valve`.
- Запятая в теле запроса означает логическое И.
- Точка с запятой означает логическое ИЛИ.
- `\+ Goal` означает, что доказать `Goal` не удалось (отрицание как неудача).
