# Лабораторная 2 — диалоговая рекомендательная система

Python 3.9+ и SWI-Prolog в PATH. Для запуска DSS сторонние Python-пакеты не нужны.
Из этой папки: `python3 recommender.py`. Для Windows: `py recommender.py`.
Тесты: `python3 -m unittest -v`.

Пример диалога:

```text
Мне нравятся: RPG, инди
один
да
```

Результат: cyberpunk_2077, stardew_valley, the_witcher_3; каждый имеет балл 1.
Имена и наборы берутся из `../lab_1/games.pl`, а не из Python-списка игр.

Формат: `<предпочтение>, <предпочтение>`; префикс `Мне нравятся:` необязателен.
Словарь: RPG/РПГ/ролевая игра; инди/инди-игры; головоломка/puzzle;
шутер/FPS; стратегия/пошаговая стратегия. Инди здесь признак производства.
Пробелы и регистр нормализуются, повторения удаляются. Вопрос о режиме:
один/вместе/любой. Вопрос о новичке: да/нет. Ошибки ввода вызывают повтор.
EOF и Ctrl+C завершают диалог; отсутствие swipl и таймаут сообщаются отдельно.
В консоли используются короткие объяснения: `совпало: puzzle; solo`,
`multi` и `для новичка` обозначают применённые фильтры. Пустой ответ выводится
как `ничего не нашлось`; при отсутствии интерпретатора — `ошибка: swipl не найден`.

`bridge.pl` загружает первую БЗ, фильтрует режим и правило новичка, собирает
совпавшие предпочтения и выдаёт JSON. Несколько предпочтений объединяются по ИЛИ,
фильтры по И. Балл — число разных совпавших предпочтений. Python сортирует по
убыванию балла, при равенстве по идентификатору. JSON передаётся через stdin,
shell не используется; пользовательский текст не вставляется в Prolog-код.

База учебная: отсутствие жанра — отсутствие сведений. Например, RPG + вместе
даёт пустой результат, хотя у baldurs_gate_3 в реальности есть этот жанр:
в учебной БЗ соответствующий факт не записан. «Новичок» означает только
выполнение учебного правила (одиночный режим, нет отмеченной сложности и
соревновательности), а не объективную оценку игры или возрастной рейтинг.
Возраст не запрашивается: возрастных ограничений в исходной БЗ нет.

Проверено восемь сценариев, неизвестные значения, пустой ввод, неверный формат,
дубликаты, отсутствие интерпретатора, восстановление диалога и EOF.
Фактические входы/ответы записаны в `../reports/evidence.json`.
