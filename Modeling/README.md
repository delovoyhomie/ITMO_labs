# Modeling

Лабораторные работы по дисциплине «Моделирование».

Каждая работа хранится в собственной папке:

- `Lab1/` — УИР 1 «Статистический анализ результатов измерений»;
- `Lab2/` — УИР 2 «Марковские модели систем массового обслуживания».

Внутри каждой папки находятся отчёт, расчётная книга и каталог `materials/` со всеми исходными материалами, относящимися к этой работе.
