# Modeling

Лабораторные работы по дисциплине «Моделирование».

Каждая работа хранится в собственной папке:

- `Lab1/` — УИР 1 «Статистический анализ результатов измерений»;
- `Lab2/` — УИР 2 «Марковские модели систем массового обслуживания».
- [`Preparation/defense-guide.html`](Preparation/defense-guide.html) — справочник для подготовки к защите обеих работ: порядок сдачи, объяснения расчётов, вопросы и самопроверка. Для интерактивного просмотра скачайте HTML и откройте в браузере.

Внутри каждой папки находятся отчёт, расчётная книга и каталог `materials/` со всеми исходными материалами, относящимися к этой работе.

В `Preparation/winmark-input/` находятся входные таблицы для ручного ввода двух моделей и контрольные результаты Python. Расчёт в WinMark пока не подтверждён; эти файлы не заменяют настоящие `.mrk` и выгрузки программы.
