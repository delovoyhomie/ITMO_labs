Содержит входы моделей и контрольные расчёты Python.
Расчёт в WinMark ещё НЕ выполнен; настоящих .mrk и HTML-выгрузок здесь нет.

1. Открой WinMark. Данные -> Ввод данных: число элементов 0,
   размер 18 для system1 или 20 для system2.
2. states.txt задаёт порядок. E1 в отчёте = p0 в WinMark.
3. Данные -> Ввод матрицы: введи ненулевые переходы transitions.txt.
   Строка = исходное состояние, столбец = следующее. Диагональ автоматически.
   matrix.txt содержит полную матрицу только для проверки.
4. Сохрани матрицу. Расчёт -> Вероятности. Проверь сумму 1 и неотрицательность.
5. Формулы -> Количество формул: 32 или 24. Вводи formulas.txt по порядку.
   Номер строки не входит в имя характеристики.
6. Расчёт -> Формулы. Сравни с expected.txt; это контроль Python.
   Проверь округление матрицы при несовпадении последних цифр.
7. Для графиков: sweep-inputs.txt содержит входы для каждой lambda.
   Меняются и поступления, и константы формул. Обслуживание неизменно.
8. Сохрани реальные system1.mrk, system2.mrk и отчёты WinMark в HTML.
   Повторно открой .mrk и проверь восстановление модели.
9. После проверки обнови формулировку о MARK в сдаваемом отчёте,
   приложив реальные результаты. До этого не заявляй этап выполненным.
