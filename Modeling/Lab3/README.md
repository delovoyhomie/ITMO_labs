## Запуск Notebook

Требуется Python 3.12 или новее. Из этой папки:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m ipykernel install --user --name modeling-lab3 --display-name "Python (Modeling Lab3)"
```

В VS Code открой `Lab3.ipynb`, выбери установленное ядро и нажми **Run All / Выполнить всё**. Первая ячейка подключает библиотеки и данные; запуск нижней ячейки после перезапуска ядра без предыдущих вызывает `NameError`.

Notebook заново обрабатывает сохранённые данные GPSS, строит графики и выполняет контроль Python. Он не запускает Windows-программу GPSS автоматически. `experiments.py` и `methodical_tables.py` пересчитывают только независимую Python-модель.

## Повторение расчётов GPSS

1. В Windows открой GPSS World Core и нужный `.gps` из `gpss-native/series`.
2. Выполни **Command → Create Simulation** (`Ctrl+Alt+S`). В тексте уже есть команды `RMULT`, `START`, `RESET`, `CLEAR` для всей серии.
3. Финальная команда `EXIT 1` сохраняет модель, симуляцию и стандартные отчёты и закрывает GPSS. Для показа на защите убери её из копии текста, чтобы окно осталось открытым.
4. Стандартные отчёты сохраняются рядом с проектом в файлах `<имя>.<номер симуляции>.<номер отчёта>.gpr`.

Для первой демонстрации подойдут `smo_baseline.gps` из `single` и `g_closed_M_M3.gps` из `series`. Файлы `closed_*` — замкнутые сети, `open_*` — разомкнутые. В сетях E2/H2 меняется обслуживание только в У3. У1 и У2 сохраняют экспоненциальный закон.

Параметр командной строки `BATCH` в использованной сборке не обеспечил автоматического запуска, поэтому выполненные опыты запускались штатной командой **Create Simulation**.

## Состав экспериментов

Для исходной СМО выполнено 12 независимых повторений по 200 000 прошедших заявок после разгона; для остальных стационарных СМО обычно 8 повторений по 60 000. Счётчик включает завершения обслуживания и отказы, как `TERMINATE 1` в GPSS. У сетей счётчик означает завершённые циклы через условный узел «0».

Переходный режим: 5 нагрузок, 3 потока (Т/А/П), 2 способа изменения нагрузки, 12 повторений. В каждом повторении отчёты сохраняются при накопленных N = 10, 20, 50, 100, 200, 300, 600, 1000, 3000, 10000, 30000, 100000. `form2.csv` содержит 360 строк; `form2_replications.csv` — 4320 отдельных наблюдений контрольных точек. В форме 2 «Заявок» означает суммарное число прошедших заявок во всех 12 повторениях; «Потери» — суммарное целое число отказов. Знаменатель П(%) и О(%) — текущее значение, по числовому примеру методички.

Замкнутые сети исследованы при изменении числа заявок и обслуживания У3 (M/E2/H2), затем проверены два способа устранения узкого места. Открытые сети сопоставлены с замкнутыми при равенстве внешней интенсивности средней производительности соответствующей замкнутой сети из GPSS при M = 3. Дополнительно варьируется загрузка У3 от 0,8 до 0,95 и сравнивается простейший и детерминированный вход.

Начальные числа: для СМО `601 + 1000*r + i`, для сетей `661 + 1000*r + i`, где r = 0…R−1, i = 0…6. Интервалы среднего построены по независимым повторениям; учтено округление стандартного отчёта GPSS до трёх знаков.

## Контроль и ограничения

- Исходная СМО сопоставлена с точным марковским решением УИР 2; фактические отклонения приведены в отчёте. Попадание всех точных значений в отдельные 95%-е интервалы не гарантируется.
- Проверены M/M/1, M/G/1, сохранение числа заявок замкнутой сети и баланс счётчиков переходного режима.
- Нулевые потери при найденной ёмкости относятся к выполненным восьми повторениям, а не к бесконечному времени наблюдения.
- Предлагаемая нагрузка и фактическая занятость приборов различаются при отказах; они показаны отдельными сериями.
- Для критического M = 6 открытая сеть почти перегружена. Сравнение законов проводится при M = 3; точные короткие стационарные оценки открытой сети в критической точке не заявляются.
- Коэффициент вариации задаёт гипотезу аппроксимации, но не доказывает вид распределения. У ожидания есть отдельная масса в нуле.
- Графики выполнены в оттенках серого. Законы различаются маркерами и типами линий; гистограммы подписаны. Цвет не используется для кодирования обязательных данных.
