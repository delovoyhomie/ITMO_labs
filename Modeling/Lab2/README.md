## Запуск notebook

Открой `Lab2.ipynb` в VS Code с расширениями Python и Jupyter либо в JupyterLab. Установи зависимости командой `python -m pip install -r requirements.txt`, выбери подготовленное Python-окружение как kernel и нажми **Run All**. На текущем компьютере подготовлено ядро **Python (ITMO Modeling 3.12)**.

Notebook строит модели и считает результаты самостоятельно. Готовая книга Excel нужна только для отдельной итоговой сверки. Время ожидания вычисляется непосредственно через вероятности состояний; формулы Литтла используются после этого для проверки. Дополнительная проверка использует независимость ветвей и произведение локальных вероятностей.

Сравнительные зависимости получены повторным решением обеих моделей для каждого λ от 0,1 до 2,0 с шагом 0,1. Вариант системы выбирается при заданном λ = 0,8, а не для всех возможных нагрузок.

Для СИСТЕМЫ_2 ёмкость накопителя П1 уменьшена с 2 до 1: фазовая модель исходной конфигурации содержит 28 состояний, а методичка допускает минимальное уменьшение ёмкости при количестве состояний более 20.

Расчёт выполнен Python-решателем. Требуемый методичкой этап работы в MARK не подтверждён.

Для ручного выполнения этапа MARK подготовлены [инструкция и входные таблицы](../Preparation/winmark-input/READ_ME_FIRST.txt): порядок состояний, ненулевые переходы, формулы и входы для варьирования. Контрольные значения в наборе рассчитаны Python и не являются выгрузкой MARK. Объяснения моделей и вопросы к защите находятся в [HTML-справочнике](../Preparation/defense-guide.html).
