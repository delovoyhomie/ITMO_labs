## Запуск notebook

Открой `Lab1.ipynb` в VS Code с расширениями Python и Jupyter или в JupyterLab. Установи зависимости в выбранное окружение командой `python -m pip install -r requirements.txt`, выбери это окружение как kernel и выполни все ячейки по порядку. Папка `materials/` должна находиться рядом с notebook.

Расчёт начинается с исходных 300 чисел из таблицы вариантов и не зависит от готовых результатов Excel. Последний раздел отдельно сверяет их с расчётной книгой; при изменении seed или отсутствии книги эта сверка пропускается. Excel и PDF не изменяются при запуске notebook.
