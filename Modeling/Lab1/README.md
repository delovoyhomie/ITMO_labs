## Моменты и обозначения

В формах 1 и 2 дисперсия считается с делителем `n−1`. Для подбора закона используются два эмпирических начальных момента: `α₁ = mean(X)`, `α₂ = mean(X²)`. Поэтому дисперсия модели `D* = α₂ − α₁²` имеет делитель `N`, а коэффициент вариации модели равен 2,8121; в форме 1 оценка коэффициента вариации равна 2,8168.

Параметры в обозначениях учебника: `q = 0,940306`, `t₁ = 4,264984`, `t₂ = 67,182245`. Средние фаз рассчитаны по формулам (2.39)–(2.41), печатная с. 66. Свободный параметр `q` выбран из условия равных вкладов фаз в общее среднее. Это дополнительный выбор в допустимом семействе.

`report-source/calculate_lab1.py` независимо рассчитывает результаты по таблице вариантов; `generate_figures.py` строит по ним графики отчёта. Эти скрипты не изменяют Excel.
