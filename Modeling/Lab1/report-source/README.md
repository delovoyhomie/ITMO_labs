# Исходник отчёта

Отчёт собран в LaTeX. Все формулы в PDF набраны средствами LaTeX, а графики строятся из итоговой книги Excel.

Порядок сборки:

1. Установить Python-пакеты `matplotlib`, `numpy` и `openpyxl`.
2. Запустить `python3 generate_figures.py`.
3. Из этой папки запустить `tectonic --outdir .. 3313_Якименко_Владислав_ЛР1.tex`.

Нужны шрифты Times New Roman и Courier New. Результат сборки сохраняется в корне `Lab1`.

Скрипт только читает книгу Excel и строит графики. Таблицы отчёта оформлены по формам 1–3 методички; доверительные полуинтервалы приведены со знаком ±. Обозначения оценок взяты из теоретического материала: математическое ожидание и дисперсия с тильдой, ε для полуинтервала.

В дополнительной проверке Льюнга–Бокса используется стандартная АКФ с общим средним и знаменателем по всей выборке: Q = 11,645951, p-value = 0,309450. Значения отличаются от прежней проверки в Excel, где в сумму Q подставлены попарные коэффициенты Пирсона. Коэффициенты в форме 3 остались попарными коэффициентами Пирсона, как в расчётной книге.
