# Исходник отчёта

Отчёт собран в LaTeX. Все формулы в PDF набраны средствами LaTeX, а графики строятся из итоговой книги Excel.

Порядок сборки:

1. Установить Python-пакеты `matplotlib`, `numpy` и `openpyxl`.
2. Запустить `python3 generate_figures.py`.
3. Запустить `tectonic 3313_Якименко_Владислав_ЛР1.tex`.
4. Поместить полученный PDF в корень папки `Lab1`.

Скрипт не изменяет книгу Excel, а только читает данные для построения семи графиков.
